# 看板口令门拦截清单（2026-10-23，家长拍板合并选项 1，DeepSeek 终审）

口令门为「门帘」口径：无设备令牌（hw-dev-token）时看板只显概览、详情点不开；服务端校验不因此增减。本清单是拦截范围的权威登记，后续新增任何可展开/可跳转区域，必须先登记本表再上线。

## 锁区内入口（锁定下被 CSS 隐藏、物理不可达，不单独拦截；可见性从属于其父区）

- 年级段内：任务卡展开（.task/.task-toggle）、昨日完成开关（[data-yd-toggle]，无顶层独立入口、随年级段锁定）、待改正音频（.corr-play）、查看原图（.torig）、打印（[data-print1]）、交作业/家务面板开启钮。
- panel-trend 内：补练动作按钮（.tr-actrow）。
- panel-shop 内：加分规则开关（#bonus-toggle）/扣分规则开关（#deduct-toggle）、积分日志开关（#log-toggle）与日志年级区（#log-g5/#log-g6）、兑换记录开关（#redeem-toggle）与商店内部元素。
- panel-achieve 内：徽章目标榜子块开关（#goals-toggle，状态 OPEN_GOALS_BLOCK）与目标榜行内详情展开（状态 OPEN_GOALS、.lib-detail），随本周徽章栏目锁定；成就带与徽章详情卡内部元素同理。
- panel-summary 内：家长版区域（#sum-parent）随小结栏目锁定；另有独立家长令牌二层（hw-parent-token，Worker /parent-auth 签发），家长版数据只经 hw-api 私有拉取、不进公开仓库（2026-10-23 DeepSeek 五条件）。
- ePrint 打印页浮层只能从任务卡打开，无顶层入口。

## 非入口（已扫描排除）

- 自动滚动引擎读取 `.collapse` 状态处（不绑点击）；无 onclick 属性、无 location.hash 深链入口（2026-10-23 全量扫描）。

## 已知局限留档

- 年级标题行为 div（role=button、无 tabindex），键盘无操作路径；看板为触屏使用（DeepSeek 受理，2026-10-23）。原生 button 类入口（栏目按钮/余额卡）的键盘 Enter/空格触发 click，走同一捕获拦截。

## 钩子登记（与「新增可展开区先登记」并列）

口令门依赖的跨块钩子必须登记于此；钩子的增删改必须与本文件在同一次提交内更新。

| 钩子 | 签名 | 用途 | 调用方 |
|---|---|---|---|
| `window.kbAskPass` | `(onOk, onCancel)` | 统一口令框：/auth 校验、签发并存储 hw-dev-token、成功回调 | 口令门拦截器；补练/ePrint 等动作流程（既有） |
| `window.kbPracticeToken` | `() => string` | 读本机设备令牌 | 口令门锁定判定 |
| `window.__kbSetGradeOpen` | `(grade /* 'g5'|'g6' */, open /* boolean */)` | 设置年级段折叠状态（同步内存状态、当日 localStorage 键与段类名） | 仅口令门收口函数 `kbCollapseAll()`；只设折叠态，不构成绕锁通道（锁定可见性由 kb-locked CSS 独立强制）。**口令门只以 `open=false` 调用（收起方向）；往展开方向使用须重新报 DeepSeek 终审（2026-10-23 终审约束）** |
| `window.__kbOpenLogSub` | `()` | 展开积分商店内积分日志子块（只开不收，已展开为 no-op） | 余额卡跳转链（bal-jump）；子块本体开关为 #log-toggle |
| `window.__kbResetShopSubs` | `()` | 复位商店内四子块为收起态（兑换本体＋链式调用 `__kbResetRuleSubs` 复位规则两块、链式调用 `__kbResetLogSub` 复位日志；各链节 try 隔离、互不阻断） | 仅口令门收口函数 `kbCollapseAll()`（收起方向） |
| `window.__kbResetRuleSubs` | `()` | 复位商店内加分/扣分规则两子块为收起态（OPEN_BONUS/OPEN_DEDUCT 清零） | `__kbResetShopSubs` 链内调用 |
| `window.__kbRestoreShopSubs` | `()` | 统一恢复四子块展开态（规则两块＋兑换在本函数同步、日志经 `__kbSyncLogSub` 同路径调用），软刷新重渲染后由数据回调触发 | 规则 fetch 回调、`renderRedeem` |
| `window.__kbResetGoalsSubs` | `()` | 复位本周徽章内目标榜：子块开关收起（OPEN_GOALS_BLOCK 清零）＋全部行内详情收起（OPEN_GOALS 清空、DOM .open 类与 chev 同步复位） | 仅口令门收口函数 `kbCollapseAll()`（与商店复位并列、try 隔离） |
